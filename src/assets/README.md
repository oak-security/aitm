BDO Grotesk is the existing Oak Security report typeface. These regular and bold
TrueType assets are the print counterparts of the web fonts used in the original
AiTM application. AiTM embeds subsets of these fonts in exported PDFs. No fonts
are fetched at runtime. The terminal uses the user's chosen terminal font.
